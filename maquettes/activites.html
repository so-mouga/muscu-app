Activités hors muscu · glisse vers le bas

Ce que tu fais à côté, pour ton IA

  • Où : dans le Journal, sur le jour, une ligne « + Activité ». Pas sur l'Accueil (il doit rester léger, et on note un padel après coup).
  • Quoi : le type (puces), la durée (− / +, par 15 min), l'effort en trois choix (Facile / Moyen / Dur), une note si tu veux. Enregistré au fil de l'eau, comme partout.
  • Pour quoi : elle sort dans les textes partagés (Bilan et séance). À l'écran, juste une ligne dans le jour et un point bleu dans le calendrier.
  • Pas remis : les calories brûlées (fausses), un compte dans le Bilan, une activité qui compterait dans tes muscles ou tes semaines tenues.
  • Écrans : le jour avant, la fenêtre de saisie, le jour après, puis les deux textes partagés.
